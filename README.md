# Rapiddex Smart Contracts

Core smart contracts for Rapiddex, a Rapiddex V3-based decentralized exchange deployed on the MST Testnet. These contracts manage pool creation, swaps, liquidity positions, on-chain state storage, and wrapped native token interaction.

## Technical Details (MST Testnet)

- **Network Name**: MST Testnet
- **Chain ID**: `91562037`
- **RPC URL**: `https://testnetrpc.mstblockchain.com`
- **WS RPC URL**: `wss://testnetrpc.mstblockchain.com`

---

## Contract Directory Structure

All source contracts reside in the `src/` directory. Flattened copies are not kept in the repo: `forge verify-contract` submits standard-JSON input directly, and a checked-in flattened copy only drifts from the source it claims to mirror. Run `forge flatten src/<Contract>.sol` if an explorer ever needs one.

### Core Contracts

*   **`src/WMST.sol`** (`Wrapped MST`): Canonical wrapped native MST token, modeled on WETH9. Periphery contracts operate exclusively on ERC20 tokens, making `WMST` a requirement to interact with native MST on the platform.
*   **`src/TestToken.sol`** (`tMUSD`): A mock ERC20 stablecoin (tMUSDC) with 6 decimals, used to bootstrap liquidity pools and facilitate swap testing. Equipped with minting capabilities owned by the contract deployer.
*   **`src/MinimalPositionDescriptor.sol`**: Provides basic metadata (`tokenURI` containing the token ID) for liquidity position NFTs. A lightweight alternative to full SVG generation libraries to save gas and deployment byte size.

### Pools (WMST / tMUSD)

Each pool was created, initialized and seeded in a single transaction by
`script/SetupPool.s.sol`. Creating a pool and funding it separately leaves a
window where anyone can swap against an empty, mispriced pool and take the
spread out of the first deposit.

| Fee tier | Pool | Position NFT | Seeded |
| :--- | :--- | :--- | :--- |
| 0.05% | `0xA0c205f7870c9b0787E3cA6cD03b41d9298aCa69` | #1 | 5 WMST / 20 tMUSD |
| 0.30% | `0xa37a6a9F85393eaB2be381Dce355dF6Ba0aC2Ced` | #2 | 5 WMST / 20 tMUSD |
| 1.00% | `0xe36E941FF88d31ac1F62c24cFcAB37Df6EB45bAB` | #3 | 5 WMST / 20 tMUSD |

All three were opened full-range at a starting price of 1 WMST = 4 tMUSD, and
each had its oracle cardinality raised to 10 — a pool left at cardinality 1
serves no usable TWAP and is trivially manipulable within a single block.

## Commands & Usage

This project uses **Foundry** for building, testing, and scripting.

### 1. Build and Compile

Compile all contracts (wrapper & core/periphery dependencies):

```bash
forge build
```

### 2. Run the test suite

```bash
forge test
```

Covers every audit finding RapidDex fixed, plus a check that
`POOL_INIT_CODE_HASH` still matches the compiled pool bytecode. That constant
is what the periphery uses to derive pool addresses and authenticate
callbacks, so a stale one breaks every swap and mint — and nothing else in the
build would catch it.

### 3. Deploy

The chain enforces a minimum 1 gwei priority fee; without the gas flags forge
underbids and every transaction is rejected.

```bash
source .env
forge script script/Deploy.s.sol:Deploy --rpc-url $RPC_URL --broadcast   --priority-gas-price 1gwei --with-gas-price 2gwei --slow
```

Writes `deployments/testnet.json`. Copy the addresses into `.env` before
creating pools.

### 4. Create and seed a pool

```bash
source .env
# fee tier, WMST amount (18dp), tMUSD amount (6dp)
forge script script/SetupPool.s.sol:SetupPool --rpc-url $RPC_URL --broadcast   --priority-gas-price 1gwei --with-gas-price 2gwei --slow   --sig "run(uint24,uint256,uint256)" 3000 5000000000000000000 20000000
```

Refuses to run with a zero amount: a pool that exists but holds nothing is
worse than no pool, because its price is frozen at initialization and never
reflects a trade.

### 5. Debugging with Cast

Use Foundry's `cast` utility to query state directly from the MST Testnet:

*   **Read a pool's price/tick data:**
    ```bash
    cast call <POOL_ADDRESS> "slot0()(uint160,int24,uint16,uint16,uint16,uint8,bool)" --rpc-url $RPC_URL
    ```
*   **Query a user's token balance:**
    ```bash
    cast call $TMUSD_ADDRESS "balanceOf(address)(uint256)" <USER_ADDRESS> --rpc-url $RPC_URL
    ```
